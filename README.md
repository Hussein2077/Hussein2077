# Hi, I'm Hussein 👋

**Mobile Software Engineer** · Flutter for Android, iOS & Web · Kotlin · Giza, Egypt

I've spent the last 4 years building Flutter apps, from live-streaming social apps to a large enterprise ERP. Today I work at **Ultimate Solutions** on **SOLIX**, an ERP built with Flutter Web, in a big Flutter team.

Most of my work is on the parts that keep a big app in good shape:

- 🧩 **Modular packages:** 30+ packages in one project, so many developers can work at the same time without breaking each other's code
- 🖥️ **Server-Driven UI:** the backend describes a screen and the app builds it, so new screens go live without a new release
- ⚡ **Heavy screens that stay fast:** large editable grids and long dynamic forms
- 💬 **Real-time features:** chat, live updates with Pusher, streams and notifications
- ✅ **Testing at every level:** unit, widget and integration tests, plus end-to-end tests with Selenium on Flutter Web

I also design APIs with backend engineers, help decide how business features should work, and enjoy helping newer developers with architecture.

On the native side, I build Android apps in Kotlin with Jetpack Compose.
